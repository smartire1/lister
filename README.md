# Lister

Semplice applicazione Flutter per la gestione di una lista di attività.

L'app permette di aggiungere attività, indicarne l'importanza, aggiornarne lo stato ed eliminarle con conferma. Mostra inoltre il numero di attività completate sul totale e conserva localmente la lista.

Il documento [DOC/LEZIONE.md](DOC/LEZIONE.md) spiega come gli scenari richiesti sono stati implementati attraverso i concetti fondamentali di Flutter.

## Avvio

```bash
flutter pub get
flutter run
```
